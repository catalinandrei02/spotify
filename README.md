# Spotify Clone

**Author:** Catalin - Andrei

**Location:** Cluj-Napoca

## Overview

This project is a learning endeavor to replicate core features of the Spotify
application using modern Android development practices.
It serves as a practical exercise to enhance skills in UI design, state
management, and integration with media services.

## Features

- **User Authentication:** Implemented sign-up and login flows.
- **Music Playback:** Stream and control music playback within the app.
- **Playlist Management:** Create, edit, and manage user playlists.
- **Search Functionality:** Search for songs, artists, and albums.

## Technologies Used

- **Programming Language:** Kotlin
- **Architecture:** MVVM (Model-View-ViewModel)
- **UI Framework:** Jetpack Compose
- **Networking:** Retrofit
- **Dependency Injection:** Dagger-Hilt
- **Asynchronous Operations:** Coroutines and Flow
- **Media Playback:** ExoPlayer

## Getting Started

To run this project locally:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/catalinandrei02/spotify.git
   cd spotify
   ```

2. **Set Up Environment:**
  - Ensure you have Android Studio installed.
  - Open the project in Android Studio.
  - Sync the project to download all dependencies.

3. **Build and Run:**
  - Connect an Android device or start an emulator.
  - Click on the 'Run' button in Android Studio.
