# Contributing to Spotify Clone

Thank you for considering contributing to this project! Since this is a personal
learning project, external contributions are currently limited, but feedback and
suggestions are always welcome.

## How to Contribute

### 1. Reporting Issues

If you encounter a bug, have a suggestion, or find something that needs
improvement, please open an issue in the GitHub repository.

- Ensure your issue has a clear title and description.
- Provide steps to reproduce the issue (if applicable).
- Suggest possible solutions if you have any.

### 2. Submitting Pull Requests

Pull requests are currently not actively accepted, but if you would like to
contribute code changes, please follow these guidelines:

1. **Fork the Repository**
   Click the "Fork" button on the top right corner of the repository page.

2. **Clone Your Fork**
   ```bash
   git clone https://github.com/your-username/spotify.git
   cd spotify
   ```

3. **Create a New Branch**
   ```bash
   git checkout -b feature-branch
   ```

4. **Make Your Changes**
  - Ensure your code follows best practices.
  - Run linting and tests before submitting.

5. **Commit and Push Your Changes**
   ```bash
   git add .
   git commit -m "Describe your changes"
   git push origin feature-branch
   ```

6. **Create a Pull Request**
  - Go to the repository on GitHub.
  - Click "Compare & pull request."
  - Provide a clear description of your changes.
  - Submit the pull request for review.

### 3. Coding Standards

- Follow Kotlin best practices and Android Jetpack guidelines.
- Maintain proper code formatting using Spotless.
- Keep commits concise and meaningful.

### 4. Code Review Process

- Reviews may take time as this is a personal project.
- Constructive feedback and discussion are encouraged.
- Ensure your PR follows the guidelines before submission.

## Questions or Suggestions?

If you have any questions, feel free to open an issue or contact me.

Happy coding! 🚀
